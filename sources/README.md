# Sources

Brand masters only: the Affinity files and raw images that the exports in `assets/` come from.

- Tracked with Git LFS (see `.gitattributes`). Run `git lfs install` once on a new machine.
- Never deployed: `.assetsignore` keeps this folder off brand.aubuscule.com.
- Working files for a single project or campaign do not belong here. They live on the NAS under `Aubuscule/<project>/<year-month campaign>/`.
